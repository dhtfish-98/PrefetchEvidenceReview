# Origin, changes and licenses

The selected source is [PoorBillionaire/Windows-Prefetch-Parser](https://github.com/PoorBillionaire/Windows-Prefetch-Parser/tree/bc1fa58e82918c887d61981ec400e290ecbc6d1e), fixed at `bc1fa58e82918c887d61981ec400e290ecbc6d1e`. All eight selected source, entry, package and attribution files were read completely and matched their Git blobs; [SOURCE_AUDIT.json](SOURCE_AUDIT.json) records bytes, lines and SHA-256. The original full Apache notice and complete Apache 2.0 text are retained. The reviewed Windows decompression helper's original Francesco Picasso attribution is preserved in NOTICE even though its mechanism is excluded.

The new parser implements complete declared arrays, ownership and graph checks, bounded strings and extents, exact integer time slots, input stability, privacy and explicit unsupported results. It replaces upstream unchecked reads, partial metrics, float time conversion, directory scanning, ctypes decompression and temporary evidence writes. This is a new finite implementation of the selected uncompressed record mechanism, with explicit differences; it is not a claim that every feature of the upstream package was rewritten.

The fixed [libyal/libscca format document](https://github.com/libyal/libscca/blob/d9ea0ceac5a971fa2856caf4fc6745f3b36cd9d9/documentation/Windows%20Prefetch%20File%20%28PF%29%20format.asciidoc) was consulted for the selected header, information, metric, trace, string and volume/reference sections. It is a reverse-engineered primary reference, not an official Microsoft format specification. Its text is not redistributed. The v26 information size is 220 bytes. The independent oracle source copies 224 bytes there, and reads modern volume references from byte eight rather than the reference document's sixteen-byte header. The new implementation follows the stated 220/16 profile. Modern reference interpretation, trace ownership and malformed-file handling are validated by independent position/value fixtures, rather than falsely described as complete oracle equivalence.

Independent exported-field checks use [EricZimmerman/PECmd](https://github.com/EricZimmerman/PECmd/tree/acdf082f1c2e946b0c358cdf6ef71607e00cfea0), fixed at `acdf082f1c2e946b0c358cdf6ef71607e00cfea0`, and its actual locked NuGet Prefetch 2026.5.2 package. Complete selected C# core review also used [EricZimmerman/Prefetch](https://github.com/EricZimmerman/Prefetch/tree/27d87a095fe0bd4b07726aec867e1c0f1aef08f9), fixed at `27d87a095fe0bd4b07726aec867e1c0f1aef08f9`. Equality of that source and the distributed NuGet binary has not been established. Main MIT source licenses are retained exactly. [ORACLE_AUDIT.json](ORACLE_AUDIT.json) records selected complete-file reviews and the bounded comparison scope.

The test entry removes PECmd's Exceptionless telemetry Startup line. On non-Windows it also removes only the early platform exit. Windows keeps that platform check. Full adapted Program.cs was reviewed. All original parser/JSON source bytes remain unchanged; the untouched archive, original/adapted hashes and precise private diff are recorded by the reproduction script. This is a **test-only PECmd entry adaptation and exported-field parsing comparison**. Native unmodified whole-tool equivalence and native Windows execution remain OPEN until separately evidenced. No telemetry credential is copied into this project's source, reports or public diff.

The optional oracle resolves 82 exact NuGet packages. [ORACLE_DEPENDENCIES.json](ORACLE_DEPENDENCIES.json) retains every package hash, nuspec identity, author/copyright, license declaration, repository and embedded license/notice hash. All 129 embedded text members are preserved byte-exact as eleven unique full reference texts in `licenses/`; two additional package-linked MIT texts are retained with retrieval identity. These are reference licenses for the optional oracle, not product runtime dependencies. Dependency implementation source was not audited exhaustively. Some Microsoft packages contain Microsoft .NET Library terms; the oracle dependency set must not be described as uniformly MIT or permissive.
